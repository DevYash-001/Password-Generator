\# 🔐 Password Generator



A secure and modern Windows password generator built with Python and CustomTkinter.



\## Features



\- 🔐 Cryptographically secure password generation

\- 🔢 Password length from 12 to 64 characters

\- 🔤 Lowercase letters

\- 🔠 Uppercase letters

\- 🔢 Numbers

\- 🔣 Symbols

\- 🛡️ Guarantees selected character categories

\- 📊 Password strength indicator

\- 👁️ Show / hide password

\- 📋 Copy password to clipboard

\- 🌙 Modern dark interface

\- 🪟 Standalone Windows executable



\## Security



Password generation uses Python's `secrets` module instead of the standard `random` module.



Generated passwords are not intentionally stored or transmitted by the application.



\## Technologies



\- Python

\- CustomTkinter

\- secrets

\- PyInstaller
